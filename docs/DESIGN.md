# Design direction

A restrained architectural project catalogue, with a cool-white canvas, system grotesk typography, generous side margins, fine rules and an aligned two-column project grid. Model thumbnails supply the color; navigation and captions stay neutral. The header mark uses three separated, fully closed axonometric volumes.

The oversized selected-model stage, offset rows and product feature sections have been removed. Each project is a direct link to its campus model. English is the first-visit default, with a remembered explicit Chinese switch. The UMich thumbnail remains north-northwest toward Hatcher Library and The Diag.

Reference sites reviewed for project-led presentation and concise navigation: https://davidchipperfield.com/ and https://www.johnpawson.com/. Their visual assets and branding are not used.
