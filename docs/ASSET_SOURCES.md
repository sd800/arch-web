# Asset sources

Campus previews are exported renders from the corresponding local campus projects. They are used here as static navigation previews; interactive models remain on their own websites. The images are cropped/resized and encoded as WebP. Their original geometry and source attribution remain documented in each campus project.

- `uchi`: `docs/previews/uchi-source.png`, exported in the browser from the complete original model of Release 26.10.18.16 (2,988,680 triangles), including the detailed Main Quad / Harper reconstruction and satellite-confirmed roof corrections. Original camera direction, center and span retained; another 11% tighter centered crop makes the campus larger. Both thumbnail sizes and the UChicago share tile use this source. Source SHA-256 `46a9f4d683904a77072744f7eb77018dfbc9c5575d0a416ef7dff0e2666ad50a`. See `docs/uchi-preview-camera.json` for capture dimensions and model digest.
- `umich`: `docs/previews/umich-diag.png`, native browser Save view export from the complete original geometry of Release 26.10.16.7; no regional LOD or simplified browsing derivatives. Uses the interactive website material preparation, cartographic surface order and terrain lighting. Original camera, framing, crop and output sizes retained. Source SHA-256 `14b361d7037e69ee84942259fa683e81cf55be91af10e840df7727876739dfde`. Capture provenance is in `docs/umich-preview-camera.json`.
- `uw`: `docs/previews/uw-core.png`, exported from UW Release 26.10.16.6; original core camera, centered crop and output sizes retained. Source SHA-256 `6760d7412331570795033c728a5ebdabaebddbb82c58e56e3dfa90b4ed2e1d3a`. Capture settings and model digest are recorded in `docs/uw-preview-camera.json`; regenerate the source view with `arch-uw/scripts/prepare_hub_preview.py` and Save view at 1440 × 975 CSS pixels.
- `ucsb`: `docs/previews/ucsb-core.png`, regenerated from the complete original geometry of Release 26.10.16.5; no regional LOD or simplified browsing derivatives. Original camera, framing, crop and output sizes retained. Source SHA-256 `b0b193d75498a62986526a65b8e1678bf94309e33fe5d2ea8164d5e770ef42e6`. Capture provenance is in `docs/ucsb-preview-camera.json`.

For UMich and UChicago, export the recorded camera through the current campus browser viewer at the exact `resolution` in its camera JSON, with the complete CAD stream and all exterior details enabled. Use **Save view**, then run `python3 scripts/encode_browser_preview.py CAMPUS /path/to/view.png`. This applies the recorded crop and encodes both thumbnail sizes. A raw-mesh depth-buffer render is unsuitable for published previews: it omits the viewer's explicit landscape ordering and can cover lawns with underlying pale terrain. The camera metadata records the exact model release, geometry digest and capture dimensions for each preview.

The website uses system Helvetica/Arial and Chinese system fonts. Manrope is retained for raster share-image generation under the SIL Open Font License. Legacy font assets keep their accompanying licenses. The monochrome atlas mark is an original SVG made for this project.
